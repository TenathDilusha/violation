Every task is scored as a violation detector against the review status: LLM results = the YES/NO answer; Rule detection = violation if the run named at least one rule; Highlights = violation if the run highlighted at least one part of the article. Sinhala and English articles are scored separately, each on the articles every task and prompt was run on in that language (few-shot example articles are left out), so the numbers can differ slightly from the other pages. The combined tables are at the bottom. Sinhala non-violations are human-reviewed; English non-violations are ASSUMED_NON_VIOLATION (random unreviewed articles, since none have been reviewed), so English precision and accuracy are only approximate. F2 weights recall twice as much as precision.

Averaged over repeated runs: gpt-4.1 and SinLlama ran every task and prompt {{ r.max_repeats }} times on the same articles. Each number is the mean over the runs, and the small line under it is the lowest–highest run (hover for every run). Gemini ran once. SinLlama reads YES/NO probabilities and quotes greedily, so its runs come out the same; gpt-4.1 answers some articles differently each time even at temperature 0.

Confidence scores ({{ model }} only, {{ score_methods|length + across_methods|length }} ways): instead of a yes/no, each article gets a number from the stored answers of a task, e.g. the share of the 3 runs that flag it (agreement), the model's token probability of YES or of VIOLATION (probability; stored for the YES/NO prompts and for the per-rule prompts of every task), or how many rules / passages it names (count). An article is a violation when its number is at least a threshold; each article is judged with the threshold that maximises F1 on all the other common articles (leave-one-out), so the threshold never sees the article it decides. The language sections reuse those decisions. Picking the best of many scores on the same articles still flatters it a little.
