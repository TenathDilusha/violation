What I did

I tested whether large language models can check Sri Lankan newspaper articles, in Sinhala and English, against the Editors' Guild Code of Professional Practice. For each article the model has to answer three questions: does it break the code? which rules? and which words break them? This page goes through the work from start to end.

1The code of conduct as data

Rules a model can judge

I turned the code into a JSON file of {{ n_rules }} rules that can be judged from the article text alone (e.g. unsourced claims, naming sex-crime victims, needless mention of caste or religion). Each rule lists what it says, what must be true for a breach, its exceptions (public interest, consent …) and clues to look for. Rules that need fact-checking, photos or newsroom knowledge were left out.

Only two answers

Every rule is either VIOLATION or NO_VIOLATION. I first allowed a third answer, "INDETERMINATE" (not sure), but removed it so every decision is a clear yes or no, and re-ran everything.

A Sinhala version

I also translated the code into Sinhala, to test whether Sinhala articles are judged better against Sinhala rules (step 6).

3The models

gpt-4.1 main model

OpenAI's model through the API, temperature 0. Used for every experiment, on every test article.

Gemini 3.5 Flash

Google's model. Ran once on the first set of articles; many calls failed because the service was overloaded, and the prepaid credits ran out before the spreadsheet articles, so its numbers are incomplete.

SinLlama 8B

A Sinhala Llama model on our own GPU (Sinhala articles only). It can't write answers, so I read how likely it thinks "YES" is versus "NO".

4Three ways to ask, three prompt styles

Every task is also scored as a yes/no detector: an article counts as "violation" if the model says YES, names a rule or highlights something.

Binary detection

The model answers one word.
YES / NO

Rule detection

The model lists the broken rules.
["2.2.a", "6.4.ii"]

Span detection

The model copies the exact words and names the rule; I find them in the article.
{"rule": "2.5", "excerpt": "…"}

Zero-shot

Just the code and the article.

Few-shot

The same, plus 3 worked example articles per language with the correct answer.

Per-rule

The model goes through all {{ n_rules }} rules one by one and gives a verdict for each.

Confidence scores instead of yes/no {{ 'best balance of precision and recall' if helped else 'no clear gain' }}

When gpt-4.1 answers YES or NO it also reports how likely each word was. I use that as a score, P(YES), and call an article a violation when the score passes a threshold. gpt-4.1 is very sure of itself: it often answers NO while still giving YES a few percent, and those articles are often real violations, so the best threshold is far below 50%.

To keep it fair, each article is judged with a threshold chosen on the other articles only (leave-one-out), so the threshold never sees the article it decides.

How the scoring works

Accuracy

Of all articles, how many the model judged correctly (violation or not).

Recall

Of the real violations, how many the model caught.

Precision

Of the articles the model flagged, how many really were violations (the rest are false alarms).

F1

One score combining both equally: high only when precision and recall are both high.

F2

One score combining both, with recall counting twice as much: missing a violation is worse than a false alarm, because a person checks every flagged article anyway. This is the main score.
